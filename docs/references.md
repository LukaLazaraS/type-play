# Reference set: AI game builders' and "Lovable for X" builders' home and pricing pages

For TypePlay's open-launch home (`/`) and pricing (`/pricing`) pages, for a reader who has never seen these sites. All
read off the public pages, signed out, headless Edge (desktop 1440×900, phone 390×844), **2026-11-20 00:30-01:10
Tbilisi** unless marked 11-19. Traffic: Similarweb visits a month, Sept 2026 (`docs/research/competitors.md`).
Shots: `refs/` in the job folder (`theirs/` = the worktree's `.impeccable/review/reviewer-20261119/theirs/`):
`*-desktop-top.png` first screen, `*-desktop.png` / `*-phone.png` whole page, `_view/*-partNofM.png` tall pages cut
up, `*-path-N-desktop.png` the walk to the first build, `*.txt` the visible text. Points: **home** 1 first screen,
2 path to the first build, 3 proof, 4 sections below the fold, 5 phone; **pricing** 6 plan cards, 7 credits
explained, 8 free tier, 9 trust, 10 better than three plain cards / confusing.

## 1. Astrocade (astrocade.com), 2.1M visits/month: a game portal first, a builder second

URLs: https://www.astrocade.com/ , https://www.astrocade.com/create (read 2026-11-20 00:33-01:04).
No pricing page: `/pricing` returns 404 (`docs/research/competitor-pricing.md` §9); creating and playing are free.

1. **First screen.** No hero, no headline on screen: the page *is* the arcade. A left rail (big gradient **Play**
   button, Home, Search, Create, Profile, Sign In, Get App) and rows of bright, YouTube-style game covers ("Recommended
   For You", "Discover More", "Players' Choice"), each with its maker's name. The h1 "Play Free Online Games or Create
   Your Own with AI" exists only for search engines (not visible). Shot: `astrocade-home-desktop-top.png`.
2. **Path to the first build.** Create → `/create`, which on first visit stacks a modal ("Astrocade MCP is here!"),
   a toast and a "$100K Creator Contest" banner (`astrocade-create-desktop.png`). Behind them: "What game would you
   like to create?", **Inspire Me**, a box "Tap to wish...". **A signed-out visitor can send**: in ~6 s the AI pitches
   a named concept back ("River Hopper", two lines, two bullets), then **"Sign in to create"**
   (`astrocade-path-2-desktop.png`). Sign-in comes after the visitor has invested an idea, before any build.
3. **Proof.** The games: hundreds of covers by real usernames in 23 genre rows. No numbers claimed, no video.
4. **Below the fold.** Only more genre rows; no explainer, no pricing, no final call to action.
5. **Phone (390).** App-like: menu, logo, **Open App** pill, search; cover rails; a bottom tab bar Home / My Arcade /
   big Play / Create / Profile (`astrocade-home-phone-top.png`). Nothing broken, no sideways scroll.

6-10. **Pricing:** none. Free to make and play, paid by the platform (ads, contests, "Earn" payouts to creators).
   Its pull is *play first*, not a sales page.

## 2. Rosebud AI (rosebud.ai), 612K visits/month: the closest game-builder reference

URLs: https://rosebud.ai/ , https://rosebud.ai/pricing (read 2026-11-20 00:34-01:05; the 11-19 pricing capture in
`theirs/rosebud-pricing-*` has the same numbers).

1. **First screen.** h1 **"Create games with AI"**, "Describe your game below.", one prompt box with a model picker
   (rosie / gpt-sol / claude-opus marked "Best"), image attach, purple **Create**; under it one honest line: "Rosie asks
   a few questions, then builds a first version you can play." Still above the fold: a rail "Top games made with
   Rosebud" (covers with titles) and the start of "Watch Rosie build a game". Shot: `rosebud-home-desktop-top.png`.
2. **Path.** Type, Create → a **sign-in modal at once** (Google, Microsoft, email), ~6 s, same page
   (`rosebud-path-2-desktop.png`). Nothing builds signed out.
3. **Proof.** 14 covers in the first-screen rail; a **demo video** "Describe a Game. Play It." (poster: the box and a
   built farm game, "TEXT → GAME"); **"More than 1 million creators have made over 2.5 million games"** and "backed by
   Y Combinator", both hidden inside an FAQ answer.
4. **Below the fold, in order:** video + 4 one-line steps (Describe it / Rosie builds it / Change anything / Publish)
   → "Make any kind of game with AI" (8 genre cards with art, "Or start from a template") → "Publish your game
   anywhere" (link, X, "Windows and Steam" on Pro plans, coding agents) → FAQ (9) → footer. **No final call to
   action.** Shots: `_view/rosebud-home-desktop-part1of2.png`, `part2of2`.
5. **Phone (390).** h1, box and Create, the rail's top showing (`rosebud-home-phone-top.png`). Nothing broken.

6. **Plan cards** (`_view/rosebud-pricing-desktop-part1of2.png`). Lead "Start free. Upgrade for more credits,
   private projects, commercial rights and code export." Five cards: **Newbie (free)** "Start free"; **Indie Dev
   $15/month**, **10x Dev $30**, **Pro $50** (badge "Best value", the only filled button), **Scale $100** (a
   credits dropdown, "2,000,000 credits"); paid buttons all "Get started". Each card: credits per month, "10,000
   refresh credits daily", an emoji persona line ("Built for aspiring game developers..."), "Everything in X, plus:",
   then features. On desktop the 5th card wraps alone onto a second row: an unbalanced grid.
7. **Credits explained: "What credits get you"**, a 2×3 grid under the cards, the reference the 11-19 review named:
   "Every plan runs on the same credits. These are rough costs; the exact amount depends on the model and the size
   of the task, and the editor shows what each turn used." Rows: **~2,000** Edit your game with Rosie, the default
   AI · **~20,000** Edit with a premium model · **200-2,000** Generate an image or sprite animation · **~1,000** a
   sound · **~2,000** a 360° skybox · **~1,000** a 3D model. It never converts to plans: the reader must work out that
   Indie's 100,000 is ~50 default edits or ~5 premium ones. No row for a *new game*, only edits.
8. **Free.** "10000 credits per week" (≈5 default edits), "in eligible regions" (FAQ), hosted, remix games, "basic"
   assets; no card needed. The free plan sounds big (10,000) and is small in practice.
9. **Trust.** FAQ (13): free?, which plan, what is a credit, run out, expire (monthly roll over once), sell games
   (10x Dev up, no commission), code / Windows (Pro up), private, branding, **cancel** ("at any time... active until
   the end of the billing period, you keep your games and links on the Free plan"), promo, referral, contact. **No
   refund policy, no merchant of record.**
10. **Better:** the credits grid in plain rows; FAQ answers to real fears (lose my games if I cancel? can I sell?);
   "We recommend starting with Pro" said plainly. **Confusing:** three credit kinds (weekly, daily, monthly) on every
   card; six-figure numbers never converted to games; commercial rights and code download locked behind $30 / $50 (the
   game is not fully yours below that); the wrapped fifth card.
