# Home page directions (2026-10-13)

Four first-viewport sketches for the TypePlay home page, made with real test games
(`packages/agent/output`) and their real prompts and build times. Each `.html` is self-contained
(images inlined; fonts from Google Fonts), each `.png` is a 1440x900 render.

| File | Direction | Role in the round |
|---|---|---|
| `a-homescreen` | **Home Screen**: the page is a phone home screen; your sentence becomes an app icon among the real games | The roll (built). Chosen by Luka 2026-10-13 |
| `b-titlescreen` | **Title Screen**: a real game plays itself behind an arcade-style title; the prompt box is "press start" | Impeccable's pick (Claude's top candidate) |
| `c-cutpaper` | **Cut-Paper Pun**: white sheet, scrawled headline, the typed sentence turns into the game mid-word (Alan Fletcher poster grammar) | Outside challenger, competitive |
| `d-canon` | **Category standard**: the dark Lovable / Bolt look, done well | The standing exit |

Declined outside worlds (not sketched): op-art textile, sneaker archive wall, Łowicz
papercut, drum-machine step row, variable-font specimen. Each gave Home Screen one
discipline: one continuous wallpaper; a strict name + sentence + minutes label on every
game; depth by overlap only; the empty slot as the invitation; hierarchy by scale alone.

The payload the decision page used: `.impeccable/decision-home.json` (git-ignored); seed key
`350cbde1`. The chosen direction's contract lives in the surface brief
(`.impeccable/surfaces/web-src-app-page-tsx.md`) and, once built, in `DESIGN.md`.
