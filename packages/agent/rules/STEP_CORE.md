## Step 1 of {STEPS}: the core game

This session builds only the playable core of what the player asked for: the rules,
controls (keyboard + touch), title, score or goal, game over / win and restart, and the
difficulty curve, in one palette with the finished look's frame (title over the game,
`ui.gd`, HUD bars with icons, draw functions shared with the buttons, status line). Leave out
the juice (particles, screen shake, sounds, floating text) and pickups or modes the player
didn't ask for: a later session adds them.
